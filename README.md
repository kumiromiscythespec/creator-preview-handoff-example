## Start with the ready-made example

No files of your own are needed for this first look. Choose **Download the checked example ZIP** above and extract `preview-handoff-example.zip`. Read `README.txt`, then open `files/preview-worksheets.png`; `manifest.json` is the inventory. The included file is a single PNG showing four fictional previews.

For an image-only look, choose **Open the PNG** above (`preview-worksheets.png`). The workflow below is the separate path for making a new example yourself; generating and saving remain separate actions.

## Try the workflow

1. Open [Preview Sheet Studio](https://preview-sheet-studio-1111.crisp-llama-2628.chatgpt.site/), a Japanese-language tool. Press **架空の教材画像で一覧PNGを作る** to make the fictional four-preview example. Review the result, then choose **PNGを保存**. Generating and saving are separate actions.
2. Open [Download Bundle Studio in English](https://download-bundle-studio-1111.crisp-llama-2628.chatgpt.site/en.html). Choose the saved PNG, enter a title and your own read-first notes, then choose **Create ZIP** and **Save ZIP**. Use the normal file-selection flow; its fictional-files button replaces your selection with text samples.
3. Open the saved ZIP yourself. Read the notes and inventory, open the PNG, and compare it with your original. For your own work, use images you prepared and checked, regenerate after editing, and review the new output before sharing.

The included example ZIP has exactly three files:

~~~text
README.txt
manifest.json
files/preview-worksheets.png
~~~

The PNG is 1600 × 1200 pixels, with four fictional worksheet previews in two columns. The ZIP's PNG was reopened and compared byte for byte with the actual browser-saved original. The package is an example of a preview-image handoff, not a delivery of a real course or product.

1. Download and extract `worksheet-preview-inputs-en.zip`. Read `README.txt` and locate the four files under `input-png/`.
2. Open [Preview Sheet Studio in English](https://preview-sheet-studio-1111.crisp-llama-2628.chatgpt.site/?lang=en). Choose those four PNGs together using **Choose images**. The tool does not accept SVG files; do not select `editable-svg/` here.
3. Change the **Title** or one image label to your own practice wording, then choose **Generate preview PNG**. Editing clears the previous output, so generate again after each change.
4. Review the text, image order and margins. **Save PNG** is a separate optional action that asks your browser to start a download. Open any saved file yourself to check it; the tool cannot confirm that saving finished.

The SVG files are optional source artwork for these fictional pages, not hosted-tool source code. Edit them in another suitable editor and export PNGs before selecting the changed pages in Preview Sheet Studio. The tool does not edit or synchronize SVG artwork.
